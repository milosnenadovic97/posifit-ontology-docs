PosiFit ontology: Description back to ToC

The PosiFit ontology is intended to describe positive-energy building retrofit projects. It is designed around the reuse and alignment of established domain ontologies. BOT is used for spatial structure, SAREF for devices and measurements, Brick for point roles and timeseries references, QUDT for units, and vCard and WGS84 for addresses and coordinates. Terms are introduced in the pf: namespace only where PosiFit requires concepts that are not covered by these existing vocabularies. This documentation therefore focuses on the PosiFit-specific classes and properties, together with the alignments that connect them to the ontologies they reuse.

measuresop back to ToC or Object Property ToC

IRI: https://w3id.org/posifit/pf#measures

Narrower than saref:observes, which SAREF documents for devices, functions and commands — a point is none of those. The device keeps its own saref:observes triples; this says which of them a given stream is. No range: here — a point carries a saref:Property or a saref:State, and `range:` takes a single CURIE. The union sits in sensing.axioms.ttl, mirroring saref:observes, which SAREF leaves range-free for the same reason.
Links a measurement point to the single quantity its stream carries.
